# 📊 Vyapar Insight – Sales & Revenue Analysis for Retail Business

## Description
Vyapar Insight is a retail analytics platform that helps businesses analyze sales performance, forecast future revenue, and identify customer purchasing patterns. The project combines data visualization, machine learning, and market basket analysis to support data-driven decision-making.

## Features
- Sales and revenue trend analysis
- Interactive Power BI dashboards
- Sales forecasting using Prophet
- Sales prediction using XGBoost
- Market Basket Analysis for product association discovery
- KPI tracking and business insights

## Technologies Used
- Python
- Power BI
- Pandas
- NumPy
- Prophet
- XGBoost
- Mlxtend
- Matplotlib

## Models Implemented

### Prophet
Used for time-series forecasting by capturing trend and seasonality patterns in sales data.

### XGBoost
Used for predictive analysis to estimate future sales and identify key revenue drivers.

### Market Basket Analysis
Used to discover frequently purchased product combinations and support cross-selling strategies.
